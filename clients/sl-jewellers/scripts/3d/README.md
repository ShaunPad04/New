# 3D models for the product pages

Each model is built from scratch in Blender (bpy 5.2, run as a Python module) and exported
as a GLB, then compressed for the web:

    gltf-transform optimize in.glb out.glb --compress meshopt --texture-compress webp --texture-size 2048

and placed in `public/models/` with the piece's `model` field in `content/collections.json`
pointing at it. The product page (`Watch3D.tsx`, `lib/watch-viewer.ts`) turns it.

Use Blender for models (or Higgsfield's 3D Jutsu), not Higgsfield's image-to-3D generators
(Tripo, Hunyuan3D): Shaun, 7 Oct 2026.

## rolex/

The Oyster-family build, first made for the GMT-Master II 126710GRNR. Measurements come off
Rolex's own catalogue image of each reference (see the notes at the top of `build.py`).

    pip install bpy numpy pillow scipy scikit-image shapely mapbox_earcut   # Python 3.13 venv
    WATCH_VARIANT=grnr python build.py      # 126710GRNR  -> gmt.glb   (watch 05)
    WATCH_VARIANT=chnr python build.py      # 126711CHNR  -> chnr.glb  (watches 16 and 39)
    python render.py chnr.blend 34,back 900 32 out/     # Cycles previews
    ROLEX_REF=m126711chnr-0002.png python compare.py out/r_34.png cmp.png

`variant.py` holds what differs between references (metals, insert and dial colours).
Textures are generated by `gmt_tex.py`; geometry by `gmt_geo.py` (signed distance fields
meshed with marching cubes) and `gmt_bracelet.py` (the Oyster bracelet).

## bars/

Cast bars from S&L's photos. `rectify.py` straightens a cut-out photo of a bar (or several:
it finds each one) into a flat texture; `build_bar.py` builds the bar from a small JSON spec
(dimensions, draft, corner and edge radii, the front and back textures, optional sleeves):

    python rectify.py front-cutout.webp tex/b00_front 1
    python build_bar.py b00.json b00.glb
